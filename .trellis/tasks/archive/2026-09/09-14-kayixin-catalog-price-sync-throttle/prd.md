# 卡易信单规格上货与价格同步限速

## Goal

避免后台货源价格同步在短时间内连续请求触发卡速售 `频率限制(10/3)`，并让已经接入履约的卡易信 API 3.0 复用现有货源批量上架流程，从目录选择单规格卡券商品、统一加价并发布到闲鱼。

## Background

- 2026-09-14 运行日志显示，同一轮价格同步在约两秒内连续查询多个卡速售商品，供应站返回“请求频繁，频率限制(10/3)”。
- `internal/automation/external_listing_price_sync.go` 当前按规则同步循环执行，没有创建并发 goroutine，但相邻货源报价请求之间没有节流。
- 卡易信 `kayixin_v3` 已实现签名、商品详情、下单与订单查询；当前未实现 `CatalogGateway`，因此不能进入目录选品页面。
- 卡易信官方文档定义：分类接口 `/api/v3/goods/getDirs`，列表接口 `/api/v3/goods/getList`，详情接口 `/api/v3/goods/getDetail`；列表可按 `dirId`、`keyWord`、`goodsType` 和 `skuType` 筛选。
- 卡易信商品类型 `goodsType=1` 是卡券，规格类型 `skuType=0` 是单规格；详情接口提供 `stockCount`、`minQuantity`、`maxQuantity`、`goodsDescribe`、`goodsDetail` 与 `buyNotice`。

## Requirements

### R1 后台价格同步串行节流

- 保留现有一条规则接一条规则的串行处理，不引入并发报价查询。
- 相邻后台货源报价请求之间至少间隔 500ms，使单个调度器在理想情况下三秒内最多发起六次报价，给供应站其他实时请求留出余量。
- 等待必须响应调度器 Context 取消，服务关闭时不得额外阻塞。
- 单个商品查询或改价失败继续记录并处理下一条规则，不改变十分钟扫描周期和现有价格计算、成本倒挂、单规格规则语义。

### R2 卡易信目录与分页商品接入

- `kayixin.Client` 实现现有 `CatalogGateway`，不新增供应商专用 HTTP 接口。
- 分类树映射 `id/name/children` 到统一 `Category`。
- 分页列表固定筛选 `goodsType=1`、`skuType=0`，按所选 `dirId` 和关键词查询。
- 正确区分卡易信响应中的总条数与总页数；统一分页响应补充总页数，前端不再依赖固定每页 50 条推算。
- 列表未提供库存时以“未知库存”表达，不误判为零库存；真正发布前必须读取详情确认正库存、在售且仍为单规格卡券。
- 商品详情映射主图、价格、库存、最小/最大数量、简介、详情和购买提醒；保留现有直充履约行为但不允许直充进入本次批量上架入口。

### R3 共用批量上架界面

- 现有卡速售批量上架面板同时展示已启用的卡速售 v2 和卡易信 v3 实例，并使用供应商名称而非写死“卡速售”。
- 目录、分页搜索、跨页选择、统一加价、发布间隔、预检、批量发布和发布后外部采购发货规则保持同一流程。
- 发布前商品详情复核改为顺序查询，避免批量选择后由浏览器同时打出多条供应站请求。
- 每个选中货源商品仍只生成一个闲鱼商品；首版只允许单规格卡券。
- 缺主图、非在售、无库存、直充或多规格商品必须在发布前被拦截，并展示可理解的错误。

## Acceptance Criteria

- [x] AC1：多个启用价格同步规则在一轮扫描中按顺序报价，相邻报价开始时间不少于 500ms，并且取消 Context 可立即结束等待。
- [x] AC2：卡速售返回单条限频或其他报价错误时，本轮继续处理后续商品，不启动并发重试。
- [x] AC3：卡易信分类接口能返回递归统一目录树，并带正确签名请求头和空 JSON 正文。
- [x] AC4：卡易信列表请求携带 `goodsType=1`、`skuType=0`、`showDirId=1`、目录、关键词和页码，`allCount` 与 `allPage` 分别归一化为总条数和总页数，前端分页数量正确。
- [x] AC5：卡易信列表中的单规格在售商品即使没有库存字段也能进入待选状态；发布前详情库存为零、状态变化或规格变化时整批不会启动。
- [x] AC6：卡易信详情中的说明、购买提醒、上下单数量和采购价能进入现有批量发布 CSV 与外部自动发货规则。
- [x] AC7：卡速售原有目录选品与批量上架行为回归通过；直充和多规格仍不可由该入口批量上架。
- [x] AC8：后端定向测试、服务端契约检查、前端类型检查与行为测试、架构检查、注释检查、前端嵌入构建和 `git diff --check` 完成；既有环境型失败单独说明。

## Out of Scope

- 不接入卡易信多规格、多个单规格或直充商品的上架。
- 不修改卡易信下单、查单、退款、回调或卡券解密协议。
- 不修改价格同步十分钟扫描周期，不增加管理员可配置的限速设置。
- 不处理本次日志中的闲鱼标题半角 `<>`、超三十天评价、商品不存在清理或闲鱼风控错误。
- 不修改数据库结构、账号凭证模型、登录、浏览器或冻结滑块 CAPTCHA 行为。

## Technical Notes

- 限速只属于后台 listing price sync 调度，不应拖慢付款采购和用户主动打开商品详情。
- 卡易信文档示例中 `allCount=2`、`allPage=1`，字段名称表明前者是总条数、后者是总页数；文档字段说明文字疑似互换，客户端按字段名和示例语义处理并覆盖测试。
- 前端不引入第二套卡易信上架组件，扩展现有目录选品组件与统一 CSV 构造逻辑。
