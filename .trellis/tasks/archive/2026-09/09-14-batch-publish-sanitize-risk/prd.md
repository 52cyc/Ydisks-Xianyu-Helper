# 批量发布文本清洗与风控分类

## Goal

让货源批量上架在提交闲鱼前清理供应站 HTML 和非法半角尖括号，正确区分平台明确拒绝与真正的远端结果未知，并在账号触发安全验证时立即停止剩余发布，避免无法重试和连续撞风控。

## Background

- 多条塔斯汀商品返回 `FAIL_BIZ_ERR_RULE_TITLE_SECURITY_CHAR_LIMITATION`；可见标题没有半角尖括号，但发布请求同时携带由货源详情与购买须知拼成的描述，当前没有 HTML 清洗。
- 当前 `ItemBatchPublishPort.PublishRemoteRow` 仅把库存权限和类目错误当成确定失败，其余 `PublishItem` 错误全部包装为 `UncertainRemotePublishError`，因此明确的 `FAIL_BIZ_*` 也被禁止重试。
- `BatchRunner` 只在 Session 失效时停止剩余行；`FAIL_SYS_USER_VALIDATE/RGV587` 被记录后仍继续发布下一行。
- 新建批次的前端默认发布间隔是 5 秒；历史批次和数据库兼容默认值保持不变。

## Requirements

### R1 发布文本统一清洗

- 在批量预检的应用层边界统一清洗标题和描述，使预览、持久化和最终 MTOP 请求使用同一文本。
- 解码常见 HTML 实体；描述移除供应站常见 HTML 标签并保留可读换行；标题和剩余正文把半角 `<`、`>` 转成全角 `＜`、`＞`。
- 移除制表符等不可见控制字符；标题折叠为单行空格，描述保留有意义的段落换行。
- 普通表格批量发布与货源目录批量上架共用同一清洗规则，不在 React 或供应商客户端各写一套。
- 空标题、空描述回退和既有价格、库存、图片、类目校验语义保持不变。

### R2 明确拒绝与未知结果分离

- 最终发布接口返回明确 `FAIL_BIZ_*` 时记录为普通发布失败，保留平台错误码和原因，修正内容后允许人工重试。
- `FAIL_SYS_USER_VALIDATE/RGV587` 记录为需要安全验证的确定失败，不附加“远端结果未知/人工核对商品列表”。
- 只有网络中断、超时/取消、响应无法解析或远端成功后检查点无法保存等无法确认结果的边界继续使用 `uncertain_remote`。
- 不改变已经发布成功但本地落库失败的防重放保护。

### R3 风控停止与节流

- 当前行触发安全验证后立即停止同一批次剩余发布；当前风险行和未执行行保持可在完成验证后人工重试的状态。
- 不自动启动或修改冻结滑块 CAPTCHA 流程，仅展示现有验证提示。
- 普通批量发布和货源目录批量上架的前端新建任务默认间隔调整为 15 秒，用户仍可在 1–3600 秒范围内修改。
- 历史批次已保存的间隔和数据库兼容默认值不迁移、不重写。

### R4 货源商品删除后的保护价

- 后台商品页自动同步价格时，只有货源详情明确返回“商品不存在”才把对应闲鱼商品售价调整为 `9999.00` 元，便于用户发现后人工核对。
- 货源实例不存在、网络超时、限流、鉴权、系统异常和其他临时错误继续只记录日志，不得改成保护价。
- 保护价改价复用既有账号状态、Cookie 条件写回、Session 恢复和本地商品价格保存链路，不新增直接 MTOP 调用。
- 待付款订单级跟价和实际采购流程不应用此兜底，避免把已有订单价格改成保护价。

## Acceptance Criteria

- [x] AC1：含 `<p>`、`<br>`、`&lt;`、`&gt;`、制表符及 CRLF 的标题/描述在预检结果中变为可读且不含平台禁止的半角尖括号或不可见控制字符。
- [x] AC2：货源批量上架生成的详情说明经过同一应用层清洗后进入最终发布请求，前端不新增供应商专用清洗分支。
- [x] AC3：`FAIL_BIZ_ERR_RULE_TITLE_SECURITY_CHAR_LIMITATION` 被保存为可人工重试的确定发布失败，不再追加“远端结果未知”。
- [x] AC4：`FAIL_SYS_USER_VALIDATE/RGV587` 被保存为安全验证失败，并立即停止剩余行；未执行行不调用 MTOP，完成验证后可通过现有重试入口恢复。
- [x] AC5：网络/解码/取消和成功后检查点保存失败仍保持 `uncertain_remote`，不会因本次修复自动重放。
- [x] AC6：两处新建批量任务 UI 默认显示 15 秒，显式用户设置和历史批次值保持原值。
- [x] AC7：聚焦 Go/前端测试、race、vet、API/架构/注释门禁、前端构建、服务构建和 `git diff --check` 完成；既有环境基线失败单独说明。
- [x] AC8：货源商品明确不存在时商品页自动同步将闲鱼售价改为 `9999.00`，并同步本地价格；限流等其他报价错误不触发改价。

## Out of Scope

- 不自动完成闲鱼安全验证，不修改任何冻结 CAPTCHA 文件、选择器、轨迹、Cookie 合并或调用顺序。
- 不自动修改已失败批次的数据库记录，也不绕过用户核对已经标记为 `uncertain_remote` 的历史行。
- 不改变单商品手工发布的交互、闲鱼标题长度策略、商品类目或供应商采购协议。
- 不新增数据库迁移、HTTP 路由或 OpenAPI operation。

## Technical Notes

- `&#x9;` 在复制结果表时可能只是制表符的展示；由于成功行也出现该标记，不能单独认定为平台拒绝根因。
- 平台错误文案同时指向标题、卖点和短标题；当前请求的 `itemTextDTO` 同时包含标题与描述，因此清洗必须覆盖两者。
- 明确收到平台失败 ret 与“远端成功但本地未保存”是不同事实，错误分类必须以可证明的远端响应为边界。
